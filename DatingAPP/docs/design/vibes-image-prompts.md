# Vibes artwork

Created on 2026-10-12 using the built-in imagegen tool. These are generated illustrative scenes, not photos of actual members or advertised venues. No source collage had suitable activity images, so each scene was generated separately.

Runtime files live in `assets/images/vibes/`, registered individually in `pubspec.yaml` and exposed through `AppAssets`. Each is a 1200 × 800 JPEG exported at quality 82. Original generator outputs remain outside the project; the app uses only the bundled JPEGs.

`VibeArtwork` maps categories and exact game choices to assets. Legacy portrait covers resolve to category scenes at display time. Uploaded covers are preserved. Games display a photo pair only when every choice has a known image; custom statements and abstract choices stay text based. Member avatars never use these scenes.
